Product Management: UML & Architecture

This page shows the complete architecture for product management including admin CRUD operations and shop display functionality.

Key Technologies

Next.js App Router React Client Components Supabase Database TypeScript Base64 Image Storage Authentication File Upload Drag & Drop Form Validation

Core Functions & Components

ProductForm

Add/edit products with image upload, validation, and Supabase operations.

ProductList

Display admin product table with edit/delete actions and responsive design.

ProductCard

Shop page product display with image, name, price, and navigation link.

ImageUpload

Drag-and-drop image upload with base64 conversion and file validation.

Dashboard

Main admin interface managing products, orders, and navigation.

Shop Page

Product grid with filtering, sorting, and category management.

Product Type Structure

type Product = {
  id: number
  name: string
  description: string
  price: number
  image_url: string
  image_data?: string      // Base64 encoded
  category: string         // "Dresses" | "Tops" | "Bottoms" | "Outerwear"
  collection?: string
  sizes: string[]         // ["XS", "S", "M", "L", "XL"]
  created_at: string
  updated_at: string
}

Key Functions Breakdown

fetchProducts()

Location: Dashboard, Shop Page

Purpose: Get all products from Supabase with fallback to sample data

Error Handling: Console log + fallback data

handleSubmit()

Location: ProductForm

Purpose: Validate form, process image, insert/update product

Validation: Required fields, image upload, price format

handleDeleteProduct()

Location: Dashboard

Purpose: Confirm deletion and remove from database

UX: Confirmation dialog + immediate UI update

onDrop()

Location: ImageUpload

Purpose: Process file upload, convert to base64

Validation: File size (2MB max), file type

Filter & Sort

Location: Shop Page

Purpose: Category filtering and price/popularity sorting

Categories: All, Dresses, Tops, Bottoms

getSampleProducts()

Location: Shop, ProductDetail

Purpose: Provide fallback data when Supabase unavailable

Development: Ensures app works offline

Error Handling & Fallbacks

  1. Database Connection: Falls back to sample/mock data
  2. Image Upload: Validates file size and handles conversion errors
  3. Form Validation: Client-side validation with user feedback
  4. Authentication: Mock client for development environment
  5. Network Issues: Graceful degradation with local storage
