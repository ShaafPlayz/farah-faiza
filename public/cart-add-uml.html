Core Functions

addToCart()

Add / merge line item then dispatch cartUpdated.

updateQuantity()

Modify quantity; remove if <= 0; persist & dispatch.

removeItem()

Filter out item; persist & dispatch.

clearCart()

Empty cart key; dispatch.

loadCart()

Hydrate state from localStorage.

updateCartCount()

Aggregate quantities for badge.

Cart Item Shape

{
  id: number,
  name: string,
  price: number,
  image_url: string,
  size: string,
  quantity: number
}

Lifecycle

  1. Fetch product (Supabase) or fallback sample.
  2. User chooses size/quantity, triggers addToCart.
  3. Cart persisted in localStorage; event broadcast.
  4. Header badge & Cart (if open) re-hydrate.
  5. Navigation to /cart reads stored JSON.

Troubleshooting If You Don't See Diagrams

  • Ensure internet access (Mermaid loaded from jsdelivr CDN).
  • Open via http://localhost:3000/cart-add-uml.html (serving from public/), not a restricted file URL with CSP limitations.
  • Check devtools console for network or CORS errors.
  • If offline, download Mermaid bundle and replace the CDN import.
